# 人財ポートフォリオマネジメント — PRD v0.0.0

ステータス：v0 確定。実装済みプロトタイプを基準に整理した要求仕様。

## 1. 背景・課題

企業経営研修では資金繰り・財務三表など「カネ」を扱う教材は存在する一方、事業戦略に対して組織・人財構成をどう設計し、内部育成と外部調達のどちらに重心を置き、後継者をどう育てるかという「ヒト」の意思決定を体系的に体験する教材は手薄だった。

本プロダクトは「組織は戦略に従う」という因果と、人財を確保できなければ戦略は実現できない現実を、数字と時間軸を伴って体験させる。

## 2. Goals

1. 「事業戦略 → 組織設計 → 人財需要 → 投資配分 → 実行 → 結果」の因果を5年間で体験する。
2. 経営者は配分方針を決め、個別採用・配置は現場が執行する役割分担を明確にする。
3. build / buy、後継者育成のリードタイム、エンゲージメント・人心掌握をスコアで可視化する。
4. 単一HTML・外部依存ゼロで、研修会場のネット環境に依存せず実行できるようにする。

### Non-goals

- 個人単位の詳細なスキルツリー・キャリアパス管理
- 複数戦略のリプレイ比較・シナリオ分岐保存
- 実在企業・実在人物を想起させる固有名詞や商標の使用

## 3. 対象ユーザー

- 経営幹部候補・管理職研修の受講者
- 研修ファシリテーター
- 人事部門の企画担当

## 4. 主要ユーザーストーリー

- 戦略選択に応じて部門別の人財需要が変わる様子を見たい。
- 年齢構成・後継者ベンチ等の現状データを見て組織設計を判断したい。
- 部門ごとに内部育成と外部調達の重心を決め、充足率・コスト・スピードの違いを見たい。
- 5年間の結果を戦略実現度・後継承継・エンゲージメント等を含む総合スコアで評価したい。
- 任期終了後も10年持続できる組織か確認したい。
- 5年間の意思決定・財務・組織データをテキストでコピーし、AIチャットで振り返り分析したい。

## 5. 機能要件

### 5.1 コアループ

1. **事業戦略** — 成長方針4択＋重点事業最大2つを選択し、部門別需要カーブを再計算する。
2. **人財レントゲン** — 総人数、平均年齢、性別比率、管理職比率、35歳未満数、年齢構成、等級構成、放置シナリオ、部門別年齢構成を表示する。
3. **組織設計** — 組織再編、人事アーキテクチャ、現場対応レバーを選択する。
4. **部門別ギャップ** — 需要・供給見込みの差と採用市場逼迫度を表示する。
5. **投資配分** — 投資強度、部門別予算シェア、内部育成⇄外部調達スタンス、報酬水準、5年後目標を設定する。
6. **経営（年次ループ）** — 現場の自動実行、人心掌握、計画的人財配転、後継者指名・育成、必要に応じてリスキリング／リストラ判断を行う。
7. **結果** — S〜Dランク、経営者力量3軸、財務変化、人財ポートフォリオ変化、10年後の持続可能性を表示し、AI分析用テキストをコピーできる。

### 5.2 スコアリング

- 総合スコア = 戦略実現度 35% + 人員ギャップ 15% + 後継承継 30% + エンゲージメント 20%
- 経営者力量審判 = 約束する力・攻める力・繋ぐ力の3軸平均
- 総合スコア88以上でも経営者力量審判70未満の場合はSランクにしない

### 5.3 現場実行

- 6調達経路（内部育成／新卒／中途エージェント／ヘッドハント／リファラル／内部異動）を投資配分方針に沿って自動実行する。
- 採用人数の丸めは決定論的に行い、わずかな配分差でスコアが乱高下しないようにする。
- 希少専門職を緊急異動の対象外とし、異動後の役職は異動先部門に応じて更新する。

### 5.4 AI分析レポート

外部APIは呼ばず、意思決定ログ・年次推移・財務・組織データ・10年後投影をテキスト化してクリップボードへコピーできるようにする。

## 6. 非機能要件

- 単一HTML・外部依存ゼロ。CDN、fetch、外部ライブラリを使わずオフラインで動作する。
- 乱数はシード可能。同一操作列の結果を再現でき、画面再描画では乱数を消費しない。
- 日本語UI。
- 実在企業・実在商標を想起させる固有名詞を含まない。

## 7. v0 成功指標

- 7フェーズを矛盾なく1周できる。
- 少なくとも1つの戦略選択で「組織は戦略に従う」の因果を明確に体験できる。
- 経営者の意思決定と現場執行結果に意図的な乖離が生まれ、結果画面で可視化される。
- 5年の任期後、良い経営ほど10年後の持続可能性も良くなることを体感できる。

## 8. v1 に向けた候補

- 部門内ロール粒度の詳細化
- 5年一括ではなく年次単位の人財計画
- スキル構成、年齢×等級マトリクス等の詳細可視化
- 複数戦略シナリオの比較・リプレイ
- 年次ループの意思決定密度の改善

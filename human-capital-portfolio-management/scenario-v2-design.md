## 0. 数値の整合方針（先に決める）

Taskのガードレールは「粗利率29%など未確認の数字を仮に固定しない」と定めている。
そこで、**姉妹作「企業経営シミュレーション」の実装値を一次情報として確認し、HPMの数値を
そこから導出する**方針を採る。以下の実装値は `management-simulation-game/index.html` から実際に読み取った。

### 0.2 現行 `v1-prototype.html` の数値を採用しない判断

`v1-prototype.html` の定数は以下で、**姉妹作と整合しないため本シナリオでは採用しない**。

| 定数 | 値 | 不採用の理由 |
|---|---|---|
| `BASE.gross` / `plan.gross` | 27.0% / 29.0% | 姉妹作の雑貨店の粗利帯（34〜52%）の外。同一シリーズの同業種として説明できない |
| `BASE.revenue` | 8,600百万円（86億円） | 総人数64人と併置すると**1人あたり売上1.34億円**。小売業としてあり得ない |
| `EXISTING_PAYROLL` | 540百万円 | 同ファイル内の部門別 `payroll` 合計（220+38+45＝303百万円）と一致しない。内部矛盾 |

いずれもプロトタイプ検証用の暫定値であり（README に明記あり）、確定仕様ではない。
**「既存の数字だから正しい」という扱いをしない**のが本再設計の起点である。

### 0.3 HPMの数値をどう決めるか（3層に分ける）

| 層 | 扱い | 具体例 |
|---|---|---|
| **A. 継承** | 姉妹作の実装値をそのまま使う | 店舗タイプ別の月商・家賃・水光・店舗人件費、粗利率の帯（34〜52%） |
| **B. 導出** | Aから計算で出す。導出式を本書に残す | 全社売上、家賃総額、店舗人件費総額 |
| **C. 新規設定** | HPM固有で姉妹作に存在しない。根拠を本書に書き、後続Taskで検証対象とする | 本部（商品部・管理部・役員）の人員構成と人件費、減価償却・広告等の非人件費、5年後目標 |

**C層は「暫定」と明示し、実装Taskで感度分析にかける。** 本書でC層を確定仕様として凍結しない。

### 0.4 世界観の接続方針

HPMは姉妹作の**続編**として接続する。

> 姉妹作でプレイヤーが創業した雑貨店が、10年かけて12店舗のチェーンに育った。
> その10年目の期首から、HPMの5年間が始まる。

これにより、業種・粗利帯・店舗別の採算構造を姉妹作から丸ごと継承でき、
「同じシリーズとして成立する」という受入条件を、設定の言い換えではなく数値の系譜として満たす。

なお **会計期間（月次の決算カレンダー）は一致させない**。姉妹作は月次12ヶ月を刻むゲームだが、
HPMは年度を単位とし月次を持たない。人財の変化は月単位では観測できないためで、
これは整合の破れではなく粒度の意図的な差である（→ §7）。

## 1. ゲームコンセプト1枚

### 学習テーマ（1文）

> **事業戦略は、それを実行できる人が育っているかどうかでしか実現しない。だから経営者は、
> 成果が出る3年前に人へ投資を決めなければならない。**

### 1枚まとめ

| 項目 | 内容 |
|---|---|
| タイトル | 人財ポートフォリオマネジメント |
| シリーズ内の役割 | 姉妹作＝**カネの時間軸**を経営する。本作＝**ヒトの時間軸**を経営する |
| プレイヤーの役割 | 12店舗の雑貨店チェーン「（仮）クラフトリンク」の**代表取締役**。任期は5年 |
| 経営の対象 | 個別の採用・配属ではなく、**部門別の人財投資配分**（採用・育成・配置転換・モチベーション施策） |
| 決めないこと | 事業戦略そのもの。**戦略は所与**として与えられる（初版の学習焦点を人財に絞るため） |
| 中心の問い | 「この戦略を実現するには、どの部門に、いつ、いくら人へ投資すべきか」 |
| 中心の制約 | ①人財投資の原資は有限 ②育成したスキルは**3年後にしか開花しない** ③人は辞める・老いる |
| ゲーム進行 | 会社/戦略の提示 → 年度ごとの人財経営判断 → 時間経過とイベント → 人財/KPI/決算の結果 → 5年後の振り返り |
| プレイ時間 | 初回40〜60分。リプレイ20分 |
| 勝利条件 | 5年後に**予定された決算**（営業利益率5.0%）を達成し、かつ次の5年を任せられる組織を残していること |

### 設計原則（Taskの原則をそのまま運用規則に落としたもの）

1. **因果を崩さない** — `戦略 → 必要な組織能力 → 必要な人財能力 → 現状ギャップ → 人財投資 → KPI → 決算`。
   この鎖のどこかを飛ばして数値だけ動く仕掛けを入れない。
2. **未来を完全には見せない** — 意思決定の時点で5年後の確定値は表示しない。
   投資の**方向と規模の妥当性**は見せるが、最適値を逆算で当てにいく操作を成立させない。
3. **時間差を最大の教材にする** — 育成投資は3年後に効く。任期5年のうち、
   **Year 3以降に効かせたい投資はYear 1・2で決めるしかない**。この非対称性がゲームの背骨。
4. **数値最適化に見せない** — スライダーを動かすと即座に5年後の利益が変わるUIは、
   本作の学習目的と逆行する（現行v1プロトタイプの最大の問題）。判断 → 時間経過 → 結果受領の順を守る。

### 2.3 組織と人財ポートフォリオ（Year 0）

| 部門 | 担当KPI | 人員 | 年間人件費 | 平均年齢 | 現状の姿 |
|---|---|---|---|---|---|
| **店舗** | 売上 | 店長12名（正社員）＋パートFTE36名 | 136百万円 | 店長 51.2歳 | 12店中4店の店長が**60歳以上**。副店長・店長候補の正社員は**ゼロ** |
| **商品部** | 粗利率 | 5名 | 35百万円 | 52.4歳 | うち3名が55歳以上。仕入先との関係とカテゴリ知識が**完全に属人化** |
| **管理部** | 販管費率 | 7名 | 40百万円 | 44.1歳 | 12店舗分の売上・在庫・勤怠を**手作業で集計**。月末は全員が処理に埋まる |
| 役員 | — | 3名 | 27百万円 | 58.0歳 | 社長（プレイヤー）＋創業以来の役員2名 |
| **合計** | | **正社員27名＋パートFTE36名** | **238百万円** | | 労働分配率 **60.2%** |

**人財ポートフォリオの3つの穴（これがゲームの初期条件）**

1. **店長ベンチがゼロ** — 12店舗に対し店長候補が1人もいない。しかもYear 5に4名が定年を迎える（確定）。
2. **商品部の知識が個人に貼り付いている** — ベテラン3名が抜けると粗利率を作る力が消える。
3. **管理部に改善する余力がない** — 手作業に埋まっており、標準化・仕組み化に着手できない。
   人を増やせば販管費率が悪化し、増やさなければ改善が始まらない。

### 2.4 競争環境

| 要素 | 状況 | 経営への効き方 |
|---|---|---|
| 競合 | 全国チェーンの大型雑貨店が商圏内に出店。価格と品揃えの幅では勝てない | 価格競争に乗ると粗利率が崩れる。**自主編集売場**でしか差別化できない |
| 出店余地 | 主要商圏はほぼ埋まった。新規出店の投資対効果が10年前より明確に低い | **店を増やして売上を作る戦い方が終わった**（＝戦略転換の理由） |
| 採用市場 | 小売の人材獲得競争が激化。店長級の中途採用単価は上昇傾向 | 外部調達（buy）は速いが高く、かつ定着しない |
| 賃金 | 最低賃金が継続的に上昇 | パート人件費が**何もしなくても毎年増える**。販管費率への恒常的な悪化圧力 |

### 2.5 経営課題（Year 0 の決算）

| 項目 | Year 0 実績 | 備考 |
|---|---|---|
| 売上 | 860百万円 | §2.2から導出 |
| 粗利率 | **46.0%** | 姉妹作のバランス型45%＋チェーンの仕入ロット効果1.0pt。帯（34〜52%）の内側【C層：暫定】 |
| 粗利 | 395.6百万円 | |
| 販管費（人件費） | 238百万円 | §2.3 |
| 販管費（非人件費） | 154百万円 | 家賃117.1＋水光6.5＋減価償却12＋広告販促8＋物流/システム他10【C層：暫定】 |
| 販管費計 | 392百万円 | |
| 販管費率 | **45.58%** | `392.0 ÷ 860` |
| **営業利益** | **3.6百万円** | `粗利395.6 − 販管費392.0`。率で書けば `860 ×（46.0% − 45.58%）` |

> **これが物語の出発点**：10年で12店舗まで広げたが、利益はほぼ残っていない（営業利益率0.4%）。
> 姉妹作の標準構成（年間営業利益32万円・経営安全余裕率1.14%）と同じ薄氷の採算構造が、
> 規模を12倍にしてもそのまま温存されている。**規模を増やしても、人が変わらなければ利益率は変わらなかった。**

## 3. 5年後の予定された決算と、所与の戦略

### 3.1 所与の戦略（プレイヤーは選ばない。与えられる）

> **「広げる経営」から「深める経営」へ。**
> 新規出店を5年間停止する。既存12店舗の商品力と運営力を上げ、
> 5年後に営業利益率5.0%を実現する。

戦略の3本柱（前任社長と取締役会で決定済み・変更不可）

| # | 柱 | 内容 |
|---|---|---|
| S1 | **自主編集売場への転換** | 仕入れた商品を並べるだけの売場をやめ、テーマで編集した売場に変える。粗利率を上げる |
| S2 | **店長が育つ会社にする** | 店長の力量で店の売上が決まる構造を認め、店長を「採る」から「育てる」へ切り替える |
| S3 | **本部を増やさずに12店舗を回す** | 管理部の人数を増やさずに業務を標準化・仕組み化し、販管費率を下げる |

**なぜ戦略を所与にするか**：初版の学習焦点を「人財ポートフォリオ設計」に絞るため。
戦略も選ばせると、プレイヤーは結果の悪さを戦略選択のせいにでき、人財判断の振り返りが成立しない。
複数戦略の比較は後続バージョンの検討事項とする。

### 3.2 5年後の予定された決算（Year 5 目標 P/L）

| 項目 | Year 0 実績 | **Year 5 目標** | 差分 | 誰が動かすか |
|---|---|---|---|---|
| 売上 | 860百万円 | **1,000百万円** | +140（+16.3%） | **店舗**（S2） |
| 粗利率 | 46.0% | **49.0%** | +3.0pt | **商品部**（S1） |
| 粗利 | 395.6百万円 | 490.0百万円 | +94.4 | |
| 販管費率 | 45.6% | **44.0%** | −1.6pt | **管理部**（S3） |
| 販管費 | 392百万円 | 440百万円 | +48 | |
| うち人件費 | 238百万円 | **280百万円** | **+42** | ← これが人財投資の上限 |
| うち非人件費 | 154百万円 | 160百万円 | +6 | |
| **営業利益** | **3.6百万円** | **50百万円** | **+46.4** | |
| **営業利益率** | **0.4%** | **5.0%** | **+4.6pt** | |

**重要な設計**：新規出店はしない。売上+140百万円は**1店あたり年商 71.7 → 83.3百万円（+16%）**で作る。
資本ではなく人で売上を作らせる構造にすることで、「カネのゲーム」との役割分担を明確にする。

### 3.3 人財投資予算の逆算式

姉妹作と同じく、**目標決算から逆算して予算枠を出す**。

```
人件費の上限 ＝ 予定粗利益 − 非人件費販管費 − 目標営業利益
             ＝ 490.0    − 160.0          − 50.0
             ＝ 280.0 百万円 / 年（Year 5 時点）
```

| | 金額 |
|---|---|
| Year 0 人件費 | 238百万円 |
| Year 5 人件費上限 | 280百万円 |
| **5年間で増やせる人件費の総枠** | **+42百万円/年** |

この42百万円を、**3部門 × 4施策（採用・育成・配置転換・モチベーション）** に、
5年間かけてどう配分するかがプレイヤーの意思決定である。
**全部の課題を同時には解けない**（3つの穴を全部埋めるには枠が足りない）ことが本作の核心。

> 注：昇給・最低賃金上昇による自然増（毎年約1.5%＝約3.5百万円/年）も同じ枠を食う。
> 何も投資しなくても枠は毎年削られる。「投資しない」は選択であって節約ではない。

## 4. 戦略 → 組織能力 → 人財課題の因果マップ

### 4.1 全体構造

```
                   【所与の戦略】
        広げる経営 → 深める経営（営業利益率 0.4% → 5.0%）
                          │
     ┌────────────────────┼────────────────────┐
     │                    │                    │
   S1 自主編集売場      S2 店長が育つ会社     S3 本部を増やさず回す
     │                    │                    │
     ▼                    ▼                    ▼
【必要な組織能力】
  商品を編集する力      店長を量産する力      業務を標準化する力
  （カテゴリ戦略・     （育成プログラム・    （手作業の仕組み化・
    仕入交渉・         評価と登用・          データで店を見る）
    PB/独自商品）       現場の任せ方）
     │                    │                    │
     ▼                    ▼                    ▼
【必要な人財能力】
  バイヤー上級スキル    店長候補の実務経験    業務設計・IT活用スキル
  （社内5名→上級3名）   （候補ゼロ→8名）     （管理部7名中→3名）
     │                    │                    │
     ▼                    ▼                    ▼
【現状ギャップ ＝ 人財課題】
  ⚠ 知識が3名の         ⚠ 候補ゼロ。         ⚠ 月次処理に全員が
    ベテランに属人化       Year5に4名定年        埋まり改善に着手不能
     │                    │                    │
     ▼                    ▼                    ▼
【人財投資（プレイヤーの意思決定）】
  採用 / 育成 / 配置転換 / モチベーション施策 を、有限の枠から配分
     │                    │                    │
     ▼ (3年遅れ)          ▼ (3年遅れ)          ▼ (3年遅れ)
【KPI】  粗利率            売上                 販管費率
     └────────────────────┼────────────────────┘
                          ▼
                     【決算 P/L】
```

### 4.2 部門別の詳細

#### 商品部 → 粗利率（S1）

| 層 | 内容 |
|---|---|
| 必要な組織能力 | カテゴリごとに「何を売る店か」を定義し、仕入先と条件交渉し、独自商品を企画できる |
| 必要な人財能力 | 上級バイヤー3名以上（Year 0 は実質2名。うち1名は58歳） |
| 現状ギャップ | 5名中3名が55歳以上。仕入先との関係が個人に帰属し、引き継ぎの仕組みがない |
| 効く投資 | **育成**（若手2名を上級へ。3年） / **採用**（中途バイヤー。即戦力だが高単価・カルチャー不適合リスク） / **配置転換**（店舗の目利き人材を商品部へ） |
| KPIへの効き方 | 部門スキル値 × モチベーション係数 → 粗利率。**1店舗ではなく全社の粗利率に一括で効く（レバレッジ最大）** |
| 固有リスク | ベテラン1名の離脱で、積み上げたスキル値が一気に下がる（属人化ペナルティ） |

#### 店舗 → 売上（S2）

| 層 | 内容 |
|---|---|
| 必要な組織能力 | 店長を計画的に育て、任せ、評価し、入れ替えられる |
| 必要な人財能力 | 店長12名＋候補8名（Year 5 の定年4名＋自然退職に備えるベンチ） |
| 現状ギャップ | 正社員は店長12名のみ。候補ゼロ。パートから正社員への登用経路が存在しない |
| 効く投資 | **育成**（パートの正社員登用＋店長研修。3年） / **採用**（新卒・中途） / **モチベーション施策**（**唯一、即年で効く**） |
| KPIへの効き方 | 12店舗に分散するため、**1人育っても全社売上は1/12しか動かない。効かせるには面で投資する必要がある** |
| 固有リスク | 育てた候補が競合へ流出する。モチベーションが低いほど流出確率が上がる |

#### 管理部 → 販管費率（S3）

| 層 | 内容 |
|---|---|
| 必要な組織能力 | 手作業を仕組みに置き換え、人数を増やさずに店舗数の増加を吸収する |
| 必要な人財能力 | 業務設計・IT活用ができる人材3名（Year 0 は0名） |
| 現状ギャップ | 7名全員が定型処理に埋まり、改善に充てられる時間がゼロ |
| 効く投資 | **育成**（リスキリング。3年） / **配置転換**（他部門から業務設計人材を移す） / **採用**（人数を増やすと販管費率が直接悪化するジレンマ） |
| KPIへの効き方 | 販管費率。**投資した人件費そのものが販管費なので、短期では必ずKPIを悪化させる**（唯一の自己矛盾部門） |
| 固有リスク | 改善が始まるまでのタイムラグ中、販管費率が悪化し続けて見える。ここで撤退すると永久に改善しない |

### 4.3 この設計がプレイヤーに突きつけるトレードオフ

| 選択 | 短期（Year 1-2） | 長期（Year 3-5） |
|---|---|---|
| 商品部に集中 | 粗利率は動かない（3年待ち） | 全社粗利率が一気に改善。レバレッジ最大 |
| 店舗に集中 | モチベーション施策なら即効。育成は3年待ち | 12店に薄く分散。効果が見えにくいが、店長定年を乗り切れる |
| 管理部に集中 | **販管費率が悪化する**（投資が費用そのもの） | 人数を増やさず回る体質になり、以後ずっと効く |
| 何もしない | 見かけ上は営業利益を守れる | Year 5 に店長4名定年＋商品部ベテラン退職で崩壊 |

**「Year 3以降に効かせたい投資は、Year 1・2で決めるしかない」** — これを体で理解させるのが本作の目的。

## 5. Year 1〜5 シナリオ（意思決定・イベント・結果）

### 5.0 1年のサイクル

```
 ① 年初：今年の人財投資を決める（3部門 × 4施策 に予算枠を配分）
 ② 確定 →「経営する」を押す。以後この年の判断は変更できない
 ③ 時間が進む：昇給・退職・加齢・育成の進捗が自動で処理される
 ④ イベントが起きる（確率イベント／確定イベント）
 ⑤ 結果を受け取る：人財ポートフォリオの変化 → 3KPI → 年度決算
 ⑥ 取締役会コメント：数字ではなく「何が起きているか」の言語化
```

**②の確定後に巻き戻せないこと**が設計の要点。スライダーを動かして5年後を見比べる操作を成立させない。

### 5.1 年表サマリ（模範解答的な1本の道筋）

| 年 | 主な意思決定 | イベント | 売上 | 粗利率 | 販管費率 | 営業利益 |
|---|---|---|---|---|---|---|
| Y0 | （期首・基準） | — | 860 | 46.0% | 45.6% | 3.6（0.4%） |
| Y1 | 3部門すべてに着手。商品部育成2名、店舗パート登用4名、管理部リスキリング2名 | ベテランバイヤー休職 | 865 | 46.0% | 46.4% | **−3.5（−0.4%）** |
| Y2 | 投資継続。モチベーション施策で流出を止める | 最低賃金+5% | 880 | 46.5% | 46.0% | 4.4（0.5%） |
| Y3 | 開花を刈り取る配分へ。店舗の面展開を追加 | 店長候補の引き抜き | 915 | 47.5% | 45.2% | **21.0（2.3%）** |
| Y4 | 商品部を上級バイヤー3名体制に。管理部は増員せず | 駅前店の賃料改定+15% | 955 | 48.3% | 44.6% | 35.3（3.7%） |
| Y5 | 承継準備。次の5年を担う体制を固める | **店長4名が定年（確定・Y0から予告済み）** | 1,000 | 49.0% | 44.0% | **50.0（5.0%）** |

> 特に Y1 の赤字転落は「正しく投資すると最初は悪化する」ことを見せるために意図的に設計している。

### 5.2 各年の詳細

#### Year 1 — 「投資した分だけ、まず悪くなる」

| | |
|---|---|
| **考えさせること** | 人への投資は、その年のP/Lには費用としてしか現れない。それでも決められるか |
| **状況提示** | 取締役会で5年計画（営業利益率5.0%）が承認された。今年の人財投資枠は+14百万円 |
| **主な意思決定** | ・商品部：若手2名を上級バイヤー育成に投入（開花はY4）<br>・店舗：パート4名を正社員登用し店長候補に（開花はY4）<br>・管理部：2名を業務設計リスキリングへ（開花はY4）<br>・3部門に分散するか、1部門に集中するかの最初の分岐 |
| **イベント（確率60%）** | **ベテランバイヤー（58歳）が体調不良で3ヶ月休職。** 主要カテゴリの仕入交渉が止まり、商品部のスキル発揮値が一時的に低下 |
| **結果** | 売上865／粗利率46.0%（改善ゼロ）／販管費率46.4%（**悪化**）／**営業利益 −3.5百万円** |
| **取締役会コメント** | 「社長、今年は赤字です。投資の中身は理解していますが、来年も同じ説明で通るとは限りません」 |
| **学習ポイント** | 属人化リスクが**現実の損失として**初年度に顕在化する。「いつか引き継がせる」では間に合わない |

#### Year 2 — 「何もしなくても、コストは毎年上がる」

| | |
|---|---|
| **考えさせること** | 人件費は固定費ではなく**増加する費用**である。現状維持は後退である |
| **状況提示** | Y1の赤字を受けて、投資を止める選択肢が提示される。止めればY2は黒字になる |
| **主な意思決定** | ・Y1投資の継続 or 中断（**中断すると育成進捗が2/3まで減衰し、Y4の開花が消える**）<br>・店舗にモチベーション施策を打つか（唯一その年に効く施策。ただし翌年に効果は持ち越さない） |
| **イベント（確定）** | **最低賃金が5%引き上げ。** パート人件費が自動で+4.5百万円。投資枠がその分削られる |
| **結果** | 売上880／粗利率46.5%（商品部の初期効果）／販管費率46.0%／営業利益 4.4百万円（0.5%） |
| **取締役会コメント** | 「黒字には戻りました。ただ、去年と同じ利益です。2年使って何が変わったのか説明できますか」 |
| **学習ポイント** | 投資枠は**自然増で毎年削られる**。「今年は様子を見る」は枠を失うだけで何も得られない |

#### Year 3 — 「育てた人は、育てた会社にいるとは限らない」

| | |
|---|---|
| **考えさせること** | 育成と定着は別の投資である。育てただけでは人は残らない |
| **状況提示** | 商品部の育成が部分開花を始め、粗利率が初めて明確に動く。ここで配分を組み替える判断が問われる |
| **主な意思決定** | ・開花が見えた部門に追加投資して伸ばすか、遅れている部門を救うか<br>・店舗：候補4名では定年4名の補充で精一杯。**面で効かせるには追加登用が必要**<br>・管理部：まだ販管費率が改善せず、撤退の誘惑が最大になる年 |
| **イベント（確率、モチベーション依存）** | **育成中の店長候補1名が競合チェーンへ転職。** Y1・Y2でモチベーション施策を打っていた場合は発生確率が大きく下がる。打っていなければ2名流出 |
| **結果** | 売上915／粗利率47.5%（**開花**）／販管費率45.2%／営業利益 21.0百万円（2.3%） |
| **取締役会コメント** | 「粗利が動き始めました。ただ、店長候補が抜けた穴は、来年お金では埋まりません」 |
| **学習ポイント** | build（育成）はbuy（採用）より安いが、**逃げられるリスク**を伴う。定着への投資は育成投資とセットで初めて成立する |

#### Year 4 — 「自分ではどうにもならない費用が乗ってくる」

| | |
|---|---|
| **考えさせること** | 外部要因で悪化した年に、人への投資を削らずにいられるか |
| **状況提示** | 3部門すべての育成が開花し、数字が最も気持ちよく伸びる年。同時に外部から費用が乗る |
| **主な意思決定** | ・商品部を上級バイヤー3名体制で確定させる（S1の達成条件）<br>・管理部は**増員せずに**改善効果だけを受け取る（S3の達成条件）<br>・賃料増を人件費削減で埋めるか、売上で吸収するか |
| **イベント（確率40%）** | **駅前大型店の賃料が改定+15%（年+4.5百万円）。** 非人件費販管費が増え、販管費率の改善幅が削られる |
| **結果** | 売上955／粗利率48.3%／販管費率44.6%／営業利益 35.3百万円（3.7%） |
| **取締役会コメント** | 「賃料は交渉しましたが、これ以上は下がりません。それでも数字が伸びているのは、店が変わったからです」 |
| **学習ポイント** | 人財投資の成果は**外部環境の悪化を吸収する余力**として現れる。利益の絶対額だけを見ると効果を過小評価する |

#### Year 5 — 「自分の任期の終わりが、会社の終わりではない」

| | |
|---|---|
| **考えさせること** | 5年後の決算だけを最適化した経営者は、何を残さなかったのか |
| **状況提示** | 任期最終年。Y0から予告されていた店長4名の定年が到来する |
| **主な意思決定** | ・最終年に短期施策（モチベーション一括投下）で数字を作りにいくか、Year 6以降のために枠を残すか<br>・後任の育成状況を確認し、承継体制を固める |
| **イベント（確定・Y0から開示済み）** | **店長4名が定年退職。** 候補が育っていれば無風。育っていなければ**4店舗の売上が一斉に低下**し、目標決算が一気に崩れる |
| **結果（成功時）** | 売上1,000／粗利率49.0%／販管費率44.0%／**営業利益 50.0百万円（5.0%）＝目標達成** |
| **結果（店長育成を怠った場合）** | 売上945／販管費率45.1%／営業利益 36.9百万円（3.9%）＝**未達**。しかも次の5年を担う人がいない |
| **学習ポイント** | **5年前に予告されていた確定イベントに、対応できていたかどうか。** 不確実性ではなく、既知の未来に手を打てたかを問う |

### 5.3 イベント設計の方針

| 種別 | 例 | 設計意図 |
|---|---|---|
| **確定イベント**（Y0で全開示） | Y2 最低賃金上昇 / Y5 店長4名定年 | 「不運だった」という言い訳を封じる。**既知の未来への備え**を評価する |
| **確率イベント**（発生月・幅を持つ） | Y1 ベテラン休職 / Y4 賃料改定 | 現実の揺らぎ。ただし**プレイの成否を単独で決めない**幅に抑える |
| **判断連動イベント** | Y3 店長候補の流出 | プレイヤーの過去の判断（モチベーション投資の有無）で発生確率が変わる。**因果を体感させる中核** |

姉妹作と同じく**乱数はシード可能**とし、同一操作列の結果を再現できるようにする（研修での比較検討に必須）。

## 6. 最終評価と振り返り設計

### 6.1 評価の4軸

任期5年の終了時に、**目標決算の達成度だけでは評価しない**。

| 軸 | 重み | 評価内容 | 測り方 |
|---|---|---|---|
| **① 目標決算の達成度** | 35% | Year 5 の営業利益率が5.0%に届いたか | 実績営業利益率 ÷ 5.0% |
| **② 人財ポートフォリオの健全性** | 30% | 3つの穴（店長ベンチ・商品部属人化・管理部余力）が塞がったか | 店長候補数 / 上級バイヤー数 / 管理部の改善充当時間、の3指標 |
| **③ 投資配分の一貫性** | 15% | 年ごとに方針がぶれず、因果が説明できる配分だったか | 年次配分の分散、および開花前に中断した投資の割合 |
| **④ 5年後の持続可能性** | 20% | Year 6〜10 に同じ体制で戦えるか | 年齢構成・後継者充足率からの10年後投影 |

**キャップ規則**（姉妹作の「総合88以上でも力量70未満はSにしない」と同じ思想）

> 軸①が100%でも、**軸②が50%未満の場合はSランクを与えない**。
> 数字だけ作って人を残さなかった経営を最高評価にしない。

### 6.2 ランク

| ランク | 条件 | 意味 |
|---|---|---|
| **S** | 総合85以上 かつ 軸②50以上 | 目標を達成し、次の5年も任せられる会社にした |
| **A** | 総合70以上 | 目標をほぼ達成。人財の穴が一部残る |
| **B** | 総合55以上 | 未達だが、投資の方向は正しかった。時間が足りなかった |
| **C** | 総合40以上 | 短期の数字を優先し、人財の課題を先送りした |
| **D** | 総合40未満 | 投資も決算も不発。5年間、何も動かなかった |

### 6.3 振り返り画面の構成

研修の価値は結果画面ではなく**振り返り**にある。以下を必ず出す。

1. **予算対実績のウォーターフォール** — Year 0 営業利益3.6百万円 → Year 5 実績まで、
   `粗利率改善 / 売上増 / 販管費率改善 / 人件費増 / 外部要因` に分解して橋渡しする。
   **どの部門の投資が、何百万円の利益を生んだかを金額で示す。**
2. **投資 → 開花 → KPIのタイムライン** — 何年に決めた投資が何年に効いたかを、
   3年のラグを含めて1本の時間軸に並べる。**本作の学習テーマそのものの可視化。**
3. **打たなかった手の提示** — 投資しなかった部門について、
   「Year 1に管理部へ投資していれば、Year 4以降の販管費率は◯pt改善していた」を提示する。
   数値は反実仮想のシミュレーション結果として明示し、確定値として見せない。
4. **確定イベントへの対応記録** — Y5の店長定年に対し、Y1〜Y4のどの時点で手を打ったか（打たなかったか）。
5. **後任への引き継ぎメモ** — プレイヤーが**自分の言葉で**「次の社長へ引き継ぐ人財課題」を1〜3行で書く欄。
   研修ファシリテーターはここを議論の起点に使う。
6. **AI分析用テキストのコピー** — 姉妹作と同様、外部API非依存で意思決定ログ・年次推移・
   人財ポートフォリオ変化をテキスト化しクリップボードへ出す。

### 6.4 研修ゴールとの対応

Product ページの研修ゴール4点への対応を明示する。

| 研修ゴール | 本設計での担保 |
|---|---|
| ① 予算策定プロセスを説明できる | §3.3 の逆算式（予定粗利益 − 非人件費 − 目標利益 ＝ 人件費上限）を、プレイヤー自身が毎年使う |
| ② 人財投資・配置の根拠を説明できる | §6.3-1 のウォーターフォールで、投資と利益を金額で結ぶ |
| ③ 目標決算の達成方法を説明できる | 3部門 → 3KPI → P/L の一意な経路（§4.1）が崩れないため、経路そのものが説明になる |
| ④ 人財リスクとヘッジ策を説明できる | 属人化（Y1）・流出（Y3）・定年（Y5）の3リスクを、体験として通過させる |

## 7. 企業経営シミュレーションとの共通点／差分

### 7.1 共通点（シリーズとして守るもの）

| 項目 | 内容 |
|---|---|
| 業種・世界観 | 雑貨店の小売業。**HPMは姉妹作で創業した店の10年後**という連続した世界（§0.4） |
| 粗利率の帯 | 34〜52%。HPMのYear 0（46.0%）・Year 5（49.0%）はいずれもこの帯の内側 |
| 損益の恒等式 | `営業利益 = 売上 ×（粗利率 − 販管費率）`。姉妹作の会計構造をそのまま使う |
| 目標からの逆算 | 目標決算を先に置き、そこから使える枠を逆算する設計思想 |
| 意思決定 → 時間経過 → 結果 | 決めてから進める。結果は後から受け取る |
| イベントによる揺らぎ | 確定・確率・判断連動の3種。シード可能な乱数で再現性を確保 |
| ランク評価＋キャップ | 総合点だけでSを出さない。質的な軸で上限を切る |
| 実装条件 | 単一HTML・外部依存ゼロ・オフライン・日本語UI・実在企業名を使わない |
| 振り返り重視 | 結果画面＋AI分析用テキストのエクスポート |

### 7.2 差分（別のゲームである理由）

| 観点 | 企業経営シミュレーション | 人財ポートフォリオマネジメント |
|---|---|---|
| **核テーマ** | 黒字でも現金が尽きれば倒産する | 戦略は、実行できる人が育っていなければ実現しない |
| **経営する資源** | **カネ**（現金・在庫・借入） | **ヒト**（人数・スキル・年齢構成・モチベーション） |
| **時間の単位** | **月次**（12ヶ月） | **年次**（5年）。人の変化は月では観測できない |
| **期間** | 1期（1年） | 5年（社長の任期） |
| **会社のステージ** | 創業〜1期目。ゼロから作る | 創業10年目・12店舗。**既にあるものを作り変える** |
| **プレイヤーの立場** | 創業者 | 事業承継した2代目社長。任期がある |
| **戦略の扱い** | プレイヤーが選ぶ（積極/バランス/堅実） | **所与**。人財判断に学習焦点を絞るため |
| **敗北条件** | **倒産**（現金が尽きる）。即死あり | 倒産なし。**5年後の未達と、人を残せなかったこと** |
| **失敗の現れ方** | その月に現金が尽きる（即時） | **3年後に人がいない**（遅効・不可逆） |
| **主要な制約** | 資金繰りのタイミング（支払と入金のズレ） | **育成の3年ラグ**と有限の人件費枠 |
| **意思決定の粒度** | 構成選択・仕入・広告・借入（実務レベル） | 部門別の投資配分（経営レベル）。個別採用はしない |
| **B/S・C/F** | **中核**（B/S恒等式の整合が生命線） | **扱わない**。P/L（売上・粗利率・販管費率・営業利益）のみ |
| **主要KPI** | 現金残高・営業利益・経営安全余裕率 | 売上・粗利率・販管費率（3部門に1対1対応） |
| **取り返しのつかなさ** | 現金ショート（その場で終わる） | 育成の機会損失（Year 1の不作為はYear 4に取り返せない） |
| **評価の質的軸** | 経営者力量（約束する力・攻める力・繋ぐ力） | 人財ポートフォリオ健全性・持続可能性 |
| **リプレイの動機** | 別の構成・別の方針を試す | **同じ制約で別の配分を試す**（どこに賭けるべきだったか） |

### 7.3 2作を続けて研修に使う場合の接続

| 順序 | 教材 | 受講者が得るもの |
|---|---|---|
| 1日目 | 企業経営シミュレーション | 「黒字でも現金が尽きる」＝**カネの時間軸**。P/Lと現金は別物である |
| 2日目 | 人財ポートフォリオマネジメント | 「人は3年かけてしか育たない」＝**ヒトの時間軸**。今年の判断が3年後の損益を決める |
| 統合 | — | **経営とは、性質の違う複数の時間軸を同時に握ることである** |

1日目で創業した店が2日目に12店舗のチェーンになっているという世界の連続性が、
この接続を説明ではなく体験として成立させる。

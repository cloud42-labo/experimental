# 人財ポートフォリオマネジメント

v0.0.0 の研修用シミュレーション・プロトタイプ。

創業10年目の店舗型小売業を舞台に、社長として次の5年間を経営し、**事業戦略と人財投資の因果関係**を体験する。姉妹プロダクト「企業経営シミュレーション」が「カネ」の時間軸を扱うのに対し、本作は「ヒト」の時間軸を扱う。

## 学習テーマ

- 「組織は戦略に従う」：戦略 → 組織設計 → 人財需要の順で考える
- 内部人財育成 ⇄ 外部人財調達（build / buy）のトレードオフ
- 後継者育成には時間がかかり、任期終了時点だけでなくその後の持続可能性が問われる
- 経営者は個別採用ではなく、投資強度・部門配分・build/buy・報酬水準を意思決定する
- エンゲージメント、人心掌握、承継を含めて経営成果を評価する

## コアループ

1. 事業戦略
2. 人財レントゲン
3. 組織設計
4. 部門別ギャップ
5. 投資配分
6. 経営（年次 × 5年）
7. 結果

## v0.0.0 の実装方針

- 日本語UI
- 単一HTML
- 外部API・CDN・外部ライブラリなし
- オフライン実行
- 乱数をシード可能にし、同一操作列の結果を再現可能にする
- 実在企業・実在商標を想起させる固有名詞は使用しない

## v0 の検証観点

- 7フェーズを矛盾なく1周できる
- 戦略選択によって組織・人財需要が変わる因果を体験できる
- 経営者の計画と現場執行の間に意図的な乖離が生まれ、結果で確認できる
- 5年の任期終了後、10年先まで持続可能な組織かを確認できる

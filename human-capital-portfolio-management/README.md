# 人財ポートフォリオマネジメント

v0.0.0 の研修用シミュレーション・プロトタイプ。

創業10年目の店舗型小売業を舞台に、社長として次の5年間を経営し、**事業戦略と人財投資の因果関係**を体験する。姉妹プロダクト「企業経営シミュレーション」が「カネ」の時間軸を扱うのに対し、本作は「ヒト」の時間軸を扱う。

## 実行

- `index.html` — v0.0.0 の既存プロトタイプ
- `v1-prototype.html` — 研修フィードバックを反映した戦略的人財配置の新コンセプト試作

`v1-prototype.html` は、**事業目標 → KPI → 人財ギャップ → 限られた予算配分 → 5年間の人財変化 → KPI → 決算**を1画面中心で試せる。商品部・管理部・店舗の3部門について、人数・スキル・年齢構成・モチベーションを比較し、採用・育成・配置転換・モチベーション施策を変更すると5年後の売上・粗利率・販管費率・営業利益が即時に変わる。

Experimental への登録時は GitHub コネクタの転送制約により、元の単一HTMLを deterministic gzip + Base64 の7分割ペイロードとして `source-parts/` に格納し、`index.html` がブラウザ上で元HTMLを復元して実行する。復元結果は元ファイルとバイト単位で一致することを確認済み。詳細は `docs/source-manifest.md` を参照。

## v1 コンセプト

中心テーマは**事業目標を達成するための戦略的人財配置**。

- 予定された決算を先に置く
- 商品部 → 粗利率、管理部 → 販管費率、店舗 → 売上、の3KPIに絞る
- 部門別人財ポートフォリオを人数・スキル・年齢構成・モチベーションで見る
- 人財投資可能額は有限とし、全課題を同時には解決できない
- 育成の時間差、高齢化・退職、人件費、モチベーションの即効性を5年軸で比較する
- UIは事業目標・人財・予算・KPI・時間軸を同時に比較する経営コックピットを中心とする

`v1-prototype.html` の数値パラメータは学習設計を検証するための暫定値であり、確定仕様ではない。

## 学習テーマ（v0.0.0）

- 「組織は戦略に従う」：戦略 → 組織設計 → 人財需要の順で考える
- 内部人財育成 ⇄ 外部人財調達（build / buy）のトレードオフ
- 後継者育成には時間がかかり、任期終了時点だけでなくその後の持続可能性が問われる
- 経営者は個別採用ではなく、投資強度・部門配分・build/buy・報酬水準を意思決定する
- エンゲージメント、人心掌握、承継を含めて経営成果を評価する

## コアループ（v0.0.0）

1. 事業戦略
2. 人財レントゲン
3. 組織設計
4. 部門別ギャップ
5. 投資配分
6. 経営（年次 × 5年）
7. 結果

## v0.0.0 の実装方針

- 日本語UI
- ソース・オブ・トゥルースは単一HTML
- 外部API・CDN・外部ライブラリなし
- オフライン実行
- 乱数をシード可能にし、同一操作列の結果を再現可能にする
- 実在企業・実在商標を想起させる固有名詞は使用しない

## v0 の検証観点

- 7フェーズを矛盾なく1周できる
- 戦略選択によって組織・人財需要が変わる因果を体験できる
- 経営者の計画と現場執行の間に意図的な乖離が生まれ、結果で確認できる
- 5年の任期終了後、10年先まで持続可能な組織かを確認できる

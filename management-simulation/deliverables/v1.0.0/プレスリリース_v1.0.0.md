## 📣 「黒字でも倒産する」を安全に体験する経営シミュレーション、プレリリースを経て正式版v1.0.0を公開

**——プロダクトオーナーの承認を得て、研修教材として本格運用フェーズへ**

雑貨店を舞台にした経営研修シミュレーション「企業経営シミュレーション」が、約半年にわたるプレリリース期間（v0.1.0〜v0.9.6）を経て、正式版v1.0.0を公開した。プレイヤーは社長として1年間（3月〜翌2月）、資本金の設定から借入計画・在庫方針・広告投資までを判断し、月次の経営会議を経て決算を迎える。

本作が一貫して伝えてきたのは「黒字でも現金が尽きれば倒産する」という、損益計算書（P/L）だけを見ていては気づけない資金繰りの現実だ。財務三表（P/L・B/S・C/F）は毎月連動して動き、11月・12月に訪れる資金の谷を乗り越えられるかどうかは、その前月までの借入判断にかかっている。台風による客足減、中核スタッフの退職、仕入先の倒産といった予期せぬイベントも、現金の薄さや在庫の抱えすぎ（＝経営の「脆さ」）に応じて被害が増幅する設計になっており、平時の備えの大切さを身をもって学ぶ構成になっている。

今回の正式リリースにあわせて、会計エンジンの不具合も1件修正した。仕入先が倒産するイベントが発生した際、本来は「発注済みの商品が納品されない」はずが、従来の実装ではその月の発注が満額そのまま在庫に計上され、支払いも通常どおり発生していた。加えてイベント固有の緊急対応コストも計上されるため、結果として二重に現金が減少する状態になっていた。今回、倒産した仕入先への当月分発注は在庫計上・支払いともに発生しないよう修正し、イベントの説明文と実際の会計処理を一致させている。

「プレリリース期間中、B/Sの整合性検証やイベント設計の見直しを重ねてきた。研修教材として受講生に安心して使ってもらえる完成度に達したと判断し、正式版として送り出す」（本作の企画担当）。

利用は`index.dist.html`をブラウザで開くだけ。外部依存ゼロの単一HTMLファイルとして配布され、研修会場のネット環境やセキュリティポリシーに左右されずに利用できる点は、プレリリース期間から変わらぬ設計思想である。

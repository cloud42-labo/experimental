# はじめてガイド
**初めて遊ぶ方へ — ゲームの目的・画面の見方・進め方**

企業経営シミュレーション v1.0.0 ／ 雑貨店を1年間経営し、資金繰りを体験する学習ゲーム

---

## 🎯 このゲームで学べること

企業経営シミュレーションは、雑貨店を1年間（3月〜翌2月）経営するビジネス体験ゲームです。

| 体験できること | なぜ重要か | ゲームでの場面 |
|---|---|---|
| 黒字でも倒産する | P/Lだけ見ていても経営は守れない | 売上好調でも12月に現金が尽きる |
| 資金繰り計画の重要性 | 現金の谷を事前に把握し手を打つ必要がある | 6月・12月の谷に備えた借入計画 |
| 財務三表の連動 | P/L・B/S・C/Fは繋がっている | 毎月の経営会議で三表を確認 |
| 経営判断のトレードオフ | 攻めと守りのバランスが結果を左右する | 在庫・広告・借入のタイミング判断 |

---

## 🗺️ 全体の流れ（フェーズ構成）

| フェーズ | 内容 | ポイント |
|---|---|---|
| ① | 会社設立 | 資本金を設定。多すぎず少なすぎず——竹構成なら3,000万が目安。 |
| ② | 経営方針 | 積極・バランス・堅実の3択。以降の選択は必ず方針と一致させること。 |
| ③ | 事業計画 | 売上・在庫・経費・借入計画を立てる。計画段階なので「見込み」。 |
| ④ | 実務（設立手続き） | 事務所→口座開設（融資相談）→設備→人員→店舗の順に契約。 |
| ⑤ | 本編（12ヶ月経営） | 毎月の経営会議で売上・在庫・広告・借入を判断。2月で決算。 |
| ⑥ | 決算レビュー | 財務三表・資金繰りグラフ・良かった点/改善点が表示される。 |

## 📱 画面の見方

### ■ ヘッダー（常時表示）
- 左上：会社名・フェーズ名・バージョン
- 右上：現預金残高（赤字表示のときは要注意）
- 銀行信用度バー（本編プレイ中のみ表示）：返済実績で上がり、借入可能額が増える

### ■ 本編の左パネル（意思決定）
- 今月の広告費・仕入方針・商品構成・支払いサイトを決める
- 借入申し込みスライダー（翌月着金）
- 「月を進める」ボタンで1ヶ月経過

### ■ 本編の右パネル（財務三表）
- P/L（損益計算書）：売上・粗利・営業利益の累計
- B/S（貸借対照表）：資産・負債・純資産の期末残高
- C/F（キャッシュフロー計算書）：毎月の現金の動き
- 資金繰り予測グラフ：今後の現金残高見通し

## ⚠️ 初心者が陥りやすい失敗

| 失敗パターン | 回避策 |
|---|---|
| 12月に現金が尽きる | 11月に借入申請する（着金まで1ヶ月かかるため） |
| 借入を申請し忘れる | 資金繰り予測グラフで「現金が薄くなる月」を確認し、その前月に申請 |
| 売上計画と在庫・広告が不一致 | 経営方針を一つ決めたら、全項目をその方針で揃える |
| 松構成で資金不足 | 松の初期投資は8,000万超。自己資金9,000万か、竹構成からスタート |
| 重大トラブル後に借入 | Sランク狙いは借入禁止。現金3,000万以上の余裕をもって経営する |

## 🏆 ランクの目安

| ランク | 称号 | 条件 |
|---|---|---|
| S | 伝説の経営者 | 実質利益2,500万以上 ＋ 借入残高ゼロ |
| A | 優秀な経営手腕 | 実質利益2,000万以上 |
| B | 安定経営を達成 | 実質利益500万以上 |
| C | なんとか黒字確保 | 実質利益0以上 |
| D | 実質赤字経営 | 実質利益マイナス（借入残高 ＞ 営業利益） |

※ 実質利益 ＝ 営業利益（累計） − 期末借入残高（短期＋長期）

## 🎓 研修での活用ガイド

### 対象・目的
- **対象**：経営幹部候補（5名程度）
- **目的**：キャッシュフロー経営の重要性を体験で理解する
- **所要時間**：約60〜90分（プレイ30〜60分 ＋ 振り返り30分）

---

### 📋 研修の進め方（3ステップ）

**① 個人プレイ（30〜60分）**
- 各自でゲームを1周プレイする
- 他の人の画面は見ない（判断を自分でさせることが重要）
- 終わったらランクと最終現金残高をメモしておく

**② 結果共有（15分）**
- 全員のランク・実質利益・期末現金残高を発表する
- 「どんな判断をしたか」を一言ずつ話してもらう
- ランクのばらつきを可視化する（ここで議論が生まれる）

**③ 振り返り討議（15分）**
- ファシリテーターが問いかけを投げて議論を深める
- 「なぜその判断をしたか」「何が盲点だったか」を引き出す

---

### 🎤 ファシリテーター向けポイント

**気づかせたいこと**
1. **「黒字でも倒産する」** — P/L（損益）だけ見ていると、現金が尽きるタイミングを見逃す
2. **借入タイミングの重要性** — 借入は申請から着金まで1ヶ月かかる。困ってから申請では遅い
3. **資本金の厚みが経営の自由度を決める** — 自己資金が厚いほど借入に頼らず判断できる
4. **固定費は売上が落ちても出続ける** — 人件費・家賃は毎月確実に出ていく

**観察ポイント**
- 倒産した人：どの月に現金が尽きたか、その前月に何をしていたか
- 高ランクの人：どのタイミングで借入を申請したか、在庫をどう調整したか
- ランクに差が出た要因：資本金の設定額、広告への投資、在庫のコントロール

---

### 💬 振り返り用の問いかけ例

**現金・資金繰りへの気づき**
- 「12月に現金が尽きた人は、11月の時点で何をしていましたか？」
- 「資金繰り予測グラフを活用できましたか？見ていた人と見ていなかった人で結果に差はありましたか？」
- 「借入を申請したのは何月でしたか？結果的に早すぎましたか、遅すぎましたか？」

**判断・意思決定への気づき**
- 「売上が好調だった月、在庫と広告をどう判断しましたか？」
- 「イベント（スタッフ退職・大口法人客離脱など）が起きたとき、どう対応しましたか？」
- 「資本金をいくらに設定しましたか？その根拠は何でしたか？」

**現実との接続**
- 「実際の業務で、現金残高と損益の両方を同時に見る機会はありますか？」
- 「月次の資金繰り予測を立てている部署・担当者は社内にいますか？」
- 「今日の体験で、自分の仕事の何を変えてみようと思いますか？」

## 📁 ファイル構成

| ファイル | 用途 |
|---|---|
| `index.html` | 開発用ソース（JSX + Babel standalone） |

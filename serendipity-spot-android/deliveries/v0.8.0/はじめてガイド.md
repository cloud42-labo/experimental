# ついでにスポット — はじめてガイド（v0.8.0）

行ってみたいけれど、そのためだけに出かけるほどではない場所。
留めておくと、近くを通ったときに知らせます。

---

## 1. 入れる

スマホのブラウザで次を開き、ダウンロードしたファイルをタップします。

```
https://github.com/cloud42-labo/experimental/releases/download/dev/app-debug.apk
```

「提供元不明のアプリ」の確認が出たら、ブラウザに対して許可してください（初回のみ）。

> **すでに古い版が入っている場合**
> 上書きでインストールできます。ただし別の環境でビルドした版が入っているときは、
> 署名が違うため上書きできません。その場合は一度アンインストールしてください。
> スポットはスプレッドシート側にあるので、ログインし直せば元に戻ります。

## 2. 最初の起動

起動すると、順に許可を求められます。

| 聞かれるもの | 選ぶもの |
| :--- | :--- |
| 位置情報 | アプリの使用時のみ許可 |
| バックグラウンドの位置情報 | **常に許可** |
| 通知 | 許可 |

**「常に許可」が要点です。** ここが「使用中のみ」だと、アプリを閉じている間に通知が
届きません。仕組み上そうなっており、アプリ側では回避できません。

あとから変えるには「設定」→「アプリ」→「ついでにスポット」→「権限」→「位置情報」。

続けて「Googleでログイン」を押し、アカウントを選びます。
スプレッドシートとドライブへのアクセスを求められるので許可してください。
あなたのドライブに `Serendipity Spot` という名前のスプレッドシートが自動で作られ、
そこがスポットの保管場所になります。

## 3. スポットを登録する

**方法は2つあります。**

**名前で探す**
上部バーの虫めがねをタップ → 「海浜幕張駅」「〇〇公園」など入力 → 右の虫めがねで検索
→ 候補を選ぶと、その場所で登録画面が開きます。名前は入力済みなので、メモだけ書いて保存。

**地図で指す**
名前のない場所（公園のあの辺、など）は、地図を直接タップします。名前を自分で付けます。

メモは「なぜ気になったか」を書いておくと、通知が来たときに役立ちます。
店名だけだと、半年後に理由を思い出せません。

## 4. 通知が来たら

登録した場所の**半径150m以内に外から入る**と、アプリを閉じていても通知が届きます。
通知にはスポットの名前とメモが出ます。タップするとアプリが開き、その場所に地図が寄ります。

寄るかどうかは、その場で決めてください。**寄らなくても構いません。**
このアプリは達成率も連続記録も数えません。

### 通知について知っておくこと

- **すぐには鳴りません。** 数十秒から数分かかります。省電力のため、Android が位置情報を
  まとめて処理するためです
- **すでに中にいる状態では鳴りません。** 一度外に出て、また入ったときに鳴ります
- **同じ場所は3時間空きます。** 毎日通る場所に登録しても、何度も鳴ることはありません

## 5. 一覧・編集・削除

画面下端の帯を上に引き上げると、登録済みスポットの一覧が出ます。

| 操作 | できること |
| :--- | :--- |
| 項目をタップ | その場所へ地図が移動する |
| 人型のアイコン | ストリートビューで周りの様子を見る |
| 鉛筆のアイコン | 名前とメモを書き換える |
| ゴミ箱のアイコン | 削除する（確認あり） |

削除するとスプレッドシートからも消えます。

## 6. データについて

スポットは**あなた自身の Google ドライブ**にあります。運営側のサーバーはありません。

- ドライブで `Serendipity Spot` を開けば、中身をそのまま見られます
- スプレッドシート上で直接編集しても構いません（アプリを開き直すと反映されます）
- アプリを消してもデータは残ります
- アプリがアクセスできるのは、このアプリが作ったファイルだけです。ドライブ全体は見えません

## 7. うまくいかないとき

| 症状 | 見るところ |
| :--- | :--- |
| 通知が来ない | 位置情報が「常に許可」か。通知が許可されているか |
| 地図が灰色 | 設定した Maps の APIキーが有効か |
| ログインで進まない | この端末の署名が Google Cloud 側に登録されているか |
| 現在地が動かない | **位置偽装アプリを使った後、解除し忘れていないか**（開発者向けオプション →「仮の現在地情報アプリを選択」→「なし」） |

下部の一覧を一番下まで引き上げると「診断」があります。ジオフェンスの登録状況と、
最後にイベントを受け取った時刻が出ます。「テスト通知」で通知が出せるかも確認できます。

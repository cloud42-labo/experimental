# deliveries

リリースバージョンごとの成果物を置く。各バージョンのフォルダは、そのバージョンの
時点の内容で固定し、以後書き換えない。

## 各バージョンに入れるもの

| ファイル | 内容 |
| :--- | :--- |
| はじめてガイド | 利用者向けの導入・使い方 |
| ユーザー向けPRD | 利用者・ステークホルダー向けに書いた製品要件文書 |
| プレスリリース-PRFAQ | Working Backwards 形式で製品価値を説明する文書 |

## アプリ本体のスナップショットについて

`experimental/CLAUDE.md` の規約では各バージョンフォルダにアプリ本体を同梱するが、
**このアプリでは入れていない**。成果物が13MB前後のAPKであり、brain の
「大きなバイナリを置かない」方針に反するため。

そのバージョンのアプリが必要な場合は、対応するコミットからビルドする。
`app/build.gradle.kts` の `versionName` がバージョンフォルダ名と対応している。

HTMLアプリのように成果物が1ファイルで軽い場合は、規約どおり同梱してよい。

# 未来の店舗生存サバイバルゲーム — 簡易プレイ手順（受講者配布用）

PoC研修でそのまま配布する1枚ものです。詳しい操作説明が必要な場合は講師に
「はじめてガイド」を確認してください（本資料は短時間で読める要約です）。

## やること（3ステップ）

### ① はじめる

1. `index.html` をダブルクリックで開く（通信は必要、インストール不要）。
2. 店舗の場所を入力する（住所検索、Google Mapsの座標貼り付け、または
   「緯度, 経度」の直接入力のいずれでもOK）。
3. 業種を選ぶ（必須）。
4. 売上高・従業員数などの店舗プロファイルは、わかる範囲でOK（空欄は0扱い）。
5. 講師から配布されたe-StatアプリケーションIDを貼り付け、「データを取得して
   開始する」を押す。

### ② 10年間、3回の意思決定に挑む

画面は「左＝いまの状況」「右＝どうするか」に分かれています。

| 見る場所 | 内容 |
| :--- | :--- |
| ①10年後の人口予測 | この商圏の人口が今後どう変わるか |
| ②ヒト・モノ・カネ | 打てる対策（例: シフトの見直し、DX導入）。**一度ONにすると以後OFFに戻せません** |
| ③診断結果 | 今の客層・採用・財務が噛み合っているかを「良好／注意／深刻」で表示 |
| ④経営判断を下す | 「保全・現状維持／改装する／商圏を拡げる／競合を叩く／撤退する」の5択を見比べて1つ選ぶ |

③を見て→②で手を打つか考えて→④で経営判断を選ぶ、という順番で進めます。
決めたら画面下の「次の期へ」を押します。これを**3年目・6年目・10年目まで
3回**繰り返すと終了です（「撤退する」を選ぶとその時点で終了します）。

### ③ ふりかえる

各回、次の3つをメモしておくと、あとの全体共有で話しやすくなります。

1. 診断結果（③）は前回からどう変わったか
2. ②で何を選んだ／見送ったか、その理由
3. ④でどれを選んだか、なぜその判断が妥当だと思ったか

## よくあるつまずき

- **データ取得に失敗する** → まずIDの貼り付けを確認。それでもダメなら少し待って再試行。
- **場所がうまく指定できない** → 「緯度, 経度」形式（例: `35.6812, 139.7671`）で直接入力。
- **お金の計算（売上予測）は出ない** → このゲームは円建ての損益シミュレーターでは
  ありません。「経営判断が人口動態・財務と噛み合っているか」を診断するツールです。

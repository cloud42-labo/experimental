# エリアデータ（研修配布用）

参加者にe-Statのアプリケーションキーを用意させないための、事前生成済み統計データの置き場。
`index.html` は起動時に `index.json` を読み、ここにあるエリアを選択肢として表示する。

**このディレクトリに置くのは公的統計から生成した数値だけ。キーや個人情報は入れない。**

## ファイル構成

```
data/areas/
  index.json          ← エリア一覧（アプリが最初に読む）
  <slug>.json         ← エリア1件分のデータ
```

`index.json`:

```json
{
  "areas": [
    { "name": "千葉市稲毛区・稲毛駅前", "file": "chiba-inage.json", "mesh_count": 110 }
  ]
}
```

各エリアファイル（`schema_version: 1`）:

```json
{
  "schema_version": 1,
  "name": "千葉市稲毛区・稲毛駅前",
  "store": { "lat": 35.6377, "lng": 140.0827 },
  "generated_at": "2026-08-10T07:20:00.000Z",
  "source": "e-Stat 地域メッシュ統計（令和2年・平成27年国勢調査、平成28年経済センサス）",
  "dataset": {
    "meshCodes": ["53402589", "..."],
    "data2020": { "53402589": { "population": 0, "pop_young": 0, "pop_active": 0, "pop_senior": 0 } },
    "data2015": { "53402589": { "population": 0, "pop_young": 0, "pop_active": 0, "pop_senior": 0 } },
    "econData": { "53402589": { "est_100": 0, "est_110": 0, "est_140": 0, "est_150": 0 } }
  }
}
```

`dataset` はe-Statの応答を整形しただけの素データで、表示用GeoJSONへの組み立ては
アプリ側の `buildMeshGeoJson()` が行う。**ライブ取得と事前生成データが同じ組み立て処理を通る**
ので、取得元の違いで診断結果が変わることはない。

## 作り方

1. `index.html` を開き、「別の場所を診断する」を開く
2. 店舗の場所（Google MapsのURL、または「緯度, 経度」）と、自分のe-Stat アプリケーションIDを入れる
3. 「取得したデータをエリアファイルとして書き出す」にチェックを入れる
4. 業種を選んで「診断を開始する」。取得が終わるとエリア名を聞かれ、`<slug>.json` がダウンロードされる
5. そのファイルをこのディレクトリに置き、`index.json` の `areas` に1行足す
   （DevTools Console に、貼り付け用の1行が出力される）

店舗座標を中心に半径5km分（1kmメッシュで約110〜130件）を取り込む。1ファイルおよそ40〜80KB。

## 更新するとき

国勢調査・経済センサスが更新されたら作り直す。`generated_at` で鮮度が分かる。
アプリ側のデータ形式を変えたときは `schema_version` を上げる（古いファイルは起動時に弾かれる）。
